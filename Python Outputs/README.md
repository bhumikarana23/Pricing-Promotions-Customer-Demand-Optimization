# Python Analysis Outputs

## Overview
This folder contains the analytical outputs generated by the Python workflow developed for the Pricing, Promotions & Customer Demand Optimization project.

The outputs present the results of data analysis through structured reports, summary tables, visualizations, and forecasting results.

## Contents

### 1. Pricing Analysis
- Discount band performance
- Category-wise revenue analysis
- Profitability summaries
- Pricing-related visualizations

### 2. Promotion Analysis
- Promotional campaign performance
- Promotion type comparisons
- Revenue and discount analysis

### 3. Customer Analytics
- RFM customer segmentation
- Customer value analysis
- Customer cohort retention analysis
- Retention heatmap

### 4. Demand Forecasting
- Category-level demand summaries
- Baseline demand forecasts
- Forecast evaluation metrics

### 5. Business Recommendations
- Pricing optimization opportunities
- Promotional strategy insights
- Customer retention opportunities
- Demand planning recommendations

## Output Formats
The generated outputs may include:
- CSV files containing analytical summaries and results
- PNG files containing charts and visualizations
- Markdown reports containing business insights and recommendations

## Generation
All outputs are automatically generated by executing:

`py run_all_analysis.py`

The analysis uses Python libraries including Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.
