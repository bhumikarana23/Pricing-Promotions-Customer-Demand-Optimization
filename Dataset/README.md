# Excel Analysis – Pricing, Promotions & Customer Demand Optimization

## Overview
This folder contains Excel-based data preparation, exploration, and business analysis for a synthetic fashion e-commerce dataset.

The objective is to organize raw business data, calculate relevant performance metrics, and identify patterns in pricing, discounts, sales, and customer behaviour.

## Key Analysis Areas
- Data inspection and preparation
- Sales and revenue analysis
- Product and category performance
- Discount distribution
- Promotional performance
- Customer and order analysis
- Inventory performance

## Excel Features
- Data cleaning and formatting
- Sorting and filtering
- Excel formulas and functions
- Pivot Tables
- Pivot Charts
- KPI calculations
- Data visualization

## Tools Used
- Microsoft Excel

## Objective
Convert raw e-commerce data into structured reports and meaningful business insights to support commercial decision-making.
