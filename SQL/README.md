# SQL Analysis – Pricing, Promotions & Customer Demand Optimization

## Overview
This folder contains SQL-based analysis of a synthetic fashion e-commerce dataset. The objective is to extract meaningful business insights through structured queries and relational data analysis.

## Dataset
The SQL analysis uses seven interconnected datasets:
- Customers
- Products
- Orders
- Order Items
- Promotions
- Sessions
- Inventory

## Key Analysis Areas
- Revenue and sales performance
- Product and category performance
- Discount and pricing analysis
- Promotional campaign evaluation
- Customer purchasing behaviour
- Order status analysis
- Inventory and demand analysis

## SQL Concepts
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions
- INNER JOIN and LEFT JOIN
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions

## Tools Used
- MySQL
- MySQL Workbench

## Objective
Transform relational e-commerce data into meaningful business metrics and insights that can support pricing, promotion, and demand management decisions.
